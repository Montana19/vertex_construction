# VERTEX

![Превью сайта VERTEX](./assets/preview.png)

**VERTEX** — адаптивный сайт вымышленной строительной компании.

Проект посвящён созданию многостраничного по структуре интерфейса с адаптацией под различные размеры экранов. В работе использованы CSS Grid, Flexbox, Media Queries и JavaScript.

🔗 **Демо:** [Посмотреть проект](https://montana19.github.io/multiadaptive_site/)

---

## ✨ Особенности проекта

- Адаптивная верстка для desktop, tablet и mobile устройств
- Многоуровневая структура корпоративного сайта
- Адаптивная навигация с CSS-бургер-меню
- Фиксированная навигационная панель
- Построение сеток с помощью CSS Grid
- Использование Flexbox для отдельных компонентов
- Перестроение структуры контента на разных разрешениях
- FAQ, реализованный с помощью нативных HTML-тегов `<details>` и `<summary>`
- Плавная прокрутка между секциями страницы
- CSS-анимация и трансформация иконки бургер-меню
- Использование CSS Custom Properties для повторяющихся значений

---

## 📱 Адаптивность

Сайт адаптируется под различные размеры экранов с помощью Media Queries.

### Основные точки адаптации

- Desktop
- 1280px и меньше
- 800px и меньше
- 391px и меньше

При уменьшении ширины экрана структура основных секций перестраивается:

| Секция | Изменение сетки |
| --- | --- |
| Статистика | 4 → 2 → 1 колонка |
| Услуги | 3 → 2 → 1 колонка |
| Портфолио | 4 → 3 → 2 → 1 колонка |
| Отзывы | 3 → 2 → 1 колонка |
| Контакты | 4 → 2 → 1 колонка |

## ⚡ JavaScript

JavaScript используется для реализации плавной навигации между секциями страницы.

При переходе по якорным ссылкам используется метод `scrollIntoView()` с плавной прокруткой.
